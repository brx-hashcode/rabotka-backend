## Après chaque mission

Les deux personnes se notent, de 1 à 5 étoiles. Le recruteur note le
travailleur, le travailleur note le recruteur. Les deux comptent.

## Pourquoi dans les deux sens

Parce que les deux côtés peuvent mal se comporter. Un recruteur qui fait
attendre, qui change le travail convenu ou qui discute le prix à la fin, ça se
voit aussi.

## Ce que ça change

Votre note moyenne s'affiche sur votre profil, et chaque évaluation fait bouger
votre score de fiabilité — vers le haut quand elle est bonne, vers le bas quand
elle est mauvaise.

## Bien noter

Notez ce qui s'est passé, pas l'humeur du moment. Une note basse sans raison
suit la personne longtemps ; une note haute donnée par facilité rend le système
inutile pour tout le monde.

## Si une note vous semble injuste

Vous ne pouvez pas la modifier vous-même, et je ne peux pas la retirer. Si elle
vous paraît abusive, ouvrez une réclamation en expliquant la mission concernée.
